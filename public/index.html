上桌之前，先知道这些。

你控制A，另外三位会独立判断。

每人初始10000游戏币，共6轮。电脑只使用自己的观察、公开信息和场上发言估价；看不到原石真值。每轮结束清算成现金，最终现金最多者胜出；同现金比鉴料正确次数，仍相同则并列。

一块石头，两次买入机会。

  1. 看料：选一个区域和特征细查，决定是否公开记录或表达判断。
  2. 暗拍：最高有效价成交，支付自己的报价；需留足500（公窗200 + 加工300）。0表示放弃。
  3. 开窗：初拍买家选择上缘、右侧或底部的一处公窗，公开该位置的色、种、裂。
  4. 复查：所有人都还能私密细查一次，然后重新交流判断。
  5. 接盘：其余三人密封报价，须留300加工费；石主接受最高价或保留，每轮只转手一次。
  6. 鉴料：所有人切割前锁定同一道题的答案，答对+200，答错或跳过无奖励。
  7. 切石：最后持有人选择加工路线，付300加工费并获得实际出货收入。

九个区域，是本Demo的简化原石模型。

点击石头上的1—9区选位置。私人打灯每次只揭露一项，公窗揭露所在格的全部三项。绿色填充表示你已知的颜色，未知区域仍保持皮壳。最终揭晓时全部公开。

颜色 0—3无明显色 → 浅色 → 明显带色 → 浓色
种水 0—3粗 → 普通 → 细腻 → 通透
裂纹 0—2未见裂 → 细裂 → 大裂

三种切法有不同条件。

保大件：外圈8格没有大裂且平均种水≥1.5时，可成大件；否则改取小件。
分料避裂：左右两列分开利用，中央带做小件；完整的侧列可做吊坠。
追色小件：优先取最多4格颜色≥2的区域，其他部分按剩料回收。

回收价按颜色、种水、裂纹、体量和取件路线计算，确认切石后不会重新抽奖。挂牌底价并不代表实际价值。

回收价的游戏内参考。

每格未扣裂纹的基础值为：105 + 种水×125 + 颜色×170；种水和颜色都达到2时再加180。细裂按89%计算，大裂按58%计算。整料还按体量乘以（0.72 + 重量kg÷12），最后再按取件路线计价并取整到50。大件成型会有溢价，失败改小件则会折价。这是本Demo的简化定价，不是真实玉石估价。

没拍到，也还有事做。

调查新位置、选择公开什么、影响对手判断、参与接盘，并回答鉴料题。系统调查记录可靠；口头发言可能夸大、保留或误导。每阶段可表达一次判断、公开一条记录，电脑会参考这些信息。

流拍、资金不足和同价。

初拍全员放弃就流拍，直接鉴料揭晓，无玩家承担买料和加工费。无人接盘或石主拒绝，就由原石主继续切石。没有贷款或提前淘汰，资金不足仍能调查、发言和答题。同价优先位每轮轮换：第1轮A→B→C→D，第2轮B→C→D→A，依此类推。

本试玩没有强制倒计时，可按自己的节奏完成。刷新页面会结束当前对局；输入相同种子可以重玩同一组原石。
